隐私政策

适用范围：万兴 ERP 本机发布器 Windows 本机软件及其 Google Drive 同步功能。

1. 收集和处理哪些数据

使用者主动提交的采购、销售、物料及附件资料；使用者明确授权的 Google Drive 中指定 ERP 文件及其版本、校验元数据；以及本机发布操作日志。为支持 Google API 调用，软件在本机持有 OAuth 访问令牌与刷新令牌。

2. 用途

仅用于执行业务文件查询、生成采购草稿、ERP 数据库版本校验、用户触发的上传或更新、异常断点续跑、附件校验与审计追踪。程序不利用 Google 账号数据开展广告画像、营销或出售数据。

3. 数据传输与第三方

数据经 Google 官方 Drive API 在本机与用户本人授权的 Google Drive 之间传输。软件不向开发方服务器回传采购单、数据库或 OAuth 凭证。本说明网页仅展示公开使用说明及隐私信息，不提供账号登录或业务数据上传功能。

4. 存储、保留与删除

业务源文件与备份由使用者在 Google Drive 和本机目录保留。软件发布前后的审计记录和恢复点为防止误操作而保留，删除时应按项目备份与审计流程操作。用户可从 Google 账号的“第三方应用和服务”页面撤销授权，也可在其电脑上清理本机令牌与程序数据。

5. 安全措施

软件通过 HTTPS 的 Google 官方 API 接口访问资料；核验文件 SHA-256 和数据库修订；上传后回读验证；存在版本冲突时停止写入；凭证存于当前用户受限目录。互联网传输和本地终端安全仍依赖 Google 与设备安全配置。

6. 权限范围与用户选择

应用请求 Drive 完整访问范围，是因为它要更新账号中原有的指定 SQLite 主库及相关文件，而非仅访问由应用新建的文件。授权由使用者自行决定；取消授权将使同步功能不可用。

7. 联系与更新

隐私问题可通过本页底部联系邮箱提出。本政策如有更新，将于本页公开显示。

Google API 数据使用

本应用对从 Google API 接收的信息的使用和向其他应用的传输遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。应用不将 Google 用户数据用于广告，不出售 Google 用户数据。
